# cpp-study

C++ 강의를 들으며 섹션별 실습 과제를 풀고 기록하는 저장소입니다.

- 빌드 환경: MSYS2 + GCC(g++) + VS Code
- 기본 빌드: `g++ -std=c++17 -Wall -Wextra main.cpp -o main`
- 작업 순서: [WORKFLOW.md](WORKFLOW.md)

## 현재 git 단계

**1단계**: `main` 브랜치에서 add, commit, push만 사용

| 단계 | 쓰는 기능 |
| --- | --- |
| 1단계 | main에서 add, commit, push |
| 2단계 | 과제마다 브랜치 작업 후 main에 merge |
| 3단계 | 브랜치 push 후 PR로 리뷰 |

## 진도표

| 섹션 | 주제 | 학습 문서 | 과제 1 | 과제 2 | 과제 3 | 과제 4 |
| --- | --- | --- | --- | --- | --- | --- |
| 05 | 복사 생성자와 임시 객체 | [문서](https://claude.ai/artifact/B12vuXQX7aMQiGTmfWeHvr) | [ ] | [ ] | [ ] | [ ] |

과제를 리뷰받고 완료하면 `[ ]`를 `[x]`로 바꿔 커밋합니다.

## 커밋 메시지 규칙

```text
[섹션/과제] 한 일
```

예시

```text
[sec05/hw2] 복사 생성자 깊은 복사 구현
[sec05/hw2] 대입 연산자 자기 대입 처리
[sec05/hw2] 리뷰 반영: delete[] 순서 수정
[sec05] 섹션 폴더 추가
[docs] 진도표 갱신
```

- 커밋은 의미 있는 단계마다 합니다: 빌드 통과, 기능 하나 완성, 리뷰 반영.
- 다 끝나고 한 번에 커밋하지 않습니다.

## 올리지 않는 것

- 강의자료(PDF 등)와 강의 예제코드: 강사의 저작물이므로 `_local/` 폴더에만 둡니다(`.gitignore`에 등록됨).
- 섹션 학습 문서: 링크만 둡니다.
- 빌드 결과물(`.exe`, `.o`).
